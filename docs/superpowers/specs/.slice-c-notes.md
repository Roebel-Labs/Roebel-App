# Slice C (category sheets) — decisions captured before the spec

- Restaurant ranking in the Eat sheet: account_votes / account_ratings
  (the org-level signal the sheet already collects), NOT menu_item_votes.
- Meal previews: order by menu_item_votes like count DESC. Dishes with no
  votes fall back (newest / is_featured / any image) rather than being hidden,
  since only 7 votes exist app-wide across 157 dishes today.
- Empfehlungen needs a curated-list table; tours/story_collections don't fit.
